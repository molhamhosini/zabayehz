# موقع ذبائح الجزيرة (Next.js)

واجهة ويب جديدة وسريعة تقرأ البيانات من نفس الـ API الذي يستخدمه التطبيق (`https://poszabayeh.com/api/v1`).
تطبيقات الجوال (Flutter) تبقى كما هي.

## المرحلة الأولى (هذه النسخة)
- الصفحة الرئيسية: البنرات، الأقسام، العروض، الأكثر طلبًا، وصل حديثًا.
- صفحة القسم مع الترتيب حسب السعر.
- البحث.
- صفحة المنتج: الوزن والعمر، طريقة التقطيع (بالصور)، التغليف، التعبئة، الأجزاء غير المرغوبة؛ والسعر يتغير حسب الاختيار.
- سلة محلية في المتصفح (إتمام الطلب في المرحلة الثانية).
- عربي من اليمين لليسار، خط IBM Plex Sans Arabic، بيانات منتج لمحركات البحث، sitemap و robots.

## التشغيل
```bash
npm install
cp .env.example .env.local   # عدّل القيم إن لزم
npm run dev                  # http://localhost:3000
```
للعمل بدون اتصال بالخادم: `MOCK_API=1 npm run dev` (يستخدم بيانات تجريبية من `fixtures/`).

## النشر
أسهل طريقة: ارفع المجلد إلى GitHub ثم اربطه بـ Vercel، وأضف المتغيرات من `.env.example`.
بعدها وجّه النطاق zabayeah.com إلى Vercel.

## البنية
- `lib/api.ts`: كل الطلبات إلى الـ API، مع تخزين مؤقت (يتجدد كل دقيقتين) وتصغير البيانات قبل إرسالها للمتصفح.
- `lib/price.ts`: حساب الخصم بنفس قاعدة التطبيق.
- `app/`: الصفحات. `components/`: المكوّنات.
